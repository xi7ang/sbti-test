**SBTI**（Silly Big Personality Test）是一款纯娱乐恶搞社交人格测试，帮你发现自己的"第二人格"。

## 人格类型

本测试包含 **27 种人格类型**，基于 5 大维度（社交 E/I、情绪稳定性 J/P/F、责任心、开放性、讨好倾向）+ 1 个隐藏维度（酒鬼检测）综合计算。

部分人格类型一览：

| 代码 | 人格名称 | 说明 |
|------|---------|------|
| CTRL | 已拿捏者 | 一切尽在掌控 |
| DEAD | 已逝世 | 对世界已无欲无求 |
| SHIT | 愤世者 | 平等攻击所有人 |
| BOSS | 老板 | 天生的领导者 |
| IMSB | 社恐达人 | 躲进小楼成一统 |
| MALO | 摆烂人 | 躺平是一门艺术 |
| DRUNK | 隐藏人格·酒鬼 | 乙醇亲和性过强... |
| ... | ... | 共 27 种人格 |

## 测试维度

- **15 道标准维度题**：社牛/社恐、卷王/躺平、情绪稳定性等
- **2 道隐藏酒鬼检测题**：满足特定条件触发隐藏人格
- **向量距离算法**：将你的答案映射到 15 维向量空间，与所有人格模板计算距离找最优匹配
